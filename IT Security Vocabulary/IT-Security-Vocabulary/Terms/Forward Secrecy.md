# Forward Secrecy

> **Domain:** [[03 - Cryptography|Cryptography]]
> **Also known as:** PFS, Perfect Forward Secrecy

Compromise of long-term keys doesn't reveal past session data. Achieved via ephemeral key exchange (DHE, ECDHE).

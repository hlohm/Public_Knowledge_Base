# CRL and OCSP

> **Domain:** [[03 - Cryptography|Cryptography]]
> **Also known as:** CRL, OCSP

Mechanisms to check if a certificate has been **revoked**. CRL = list, OCSP = online query. OCSP stapling reduces privacy/latency issues.

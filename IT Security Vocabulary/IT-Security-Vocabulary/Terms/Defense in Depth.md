# Defense in Depth

> **Domain:** [[01 - Core Principles|Core Principles & Models]]

Layer multiple independent controls so no single failure compromises the system. The 'onion' model.

**Context.** Origin: military doctrine. Modern updates: Zero Trust replaces *perimeter* depth with *per-request* depth.

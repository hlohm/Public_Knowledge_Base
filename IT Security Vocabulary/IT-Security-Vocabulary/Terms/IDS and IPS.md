# IDS and IPS

> **Domain:** [[05 - Network Security|Network Security]]
> **Also known as:** IDS, IPS

**I**ntrusion **D**etection / **P**revention **S**ystem. IDS detects and alerts; IPS detects and **blocks**. Can be network-based (NIDS) or host-based (HIDS).

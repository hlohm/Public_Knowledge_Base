# KDF

> **Domain:** [[03 - Cryptography|Cryptography]]
> **Also known as:** Key Derivation Function

**K**ey **D**erivation **F**unction. Turns a password into a key, deliberately slowly. Modern: **Argon2**; older but solid: **bcrypt**, **scrypt**, **PBKDF2**.

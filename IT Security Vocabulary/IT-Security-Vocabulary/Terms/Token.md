# Token

> **Domain:** [[04 - Identity and Access Management|Identity & Access Management]]
> **Also known as:** Access Token, Refresh Token, ID Token

**Access** token: short-lived, presented to APIs. **Refresh** token: longer-lived, used to get new access tokens. **ID** token (OIDC): proves user identity to the client app.

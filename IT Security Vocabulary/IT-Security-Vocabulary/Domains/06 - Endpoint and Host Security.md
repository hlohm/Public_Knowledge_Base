# Endpoint & Host Security

> Where the user lives — and where attackers love to land. The lineage AV → EPP → EDR → XDR → MDR captures most of the marketing in this space.

## Terms in this domain

- [[Antivirus]] — Classic signature-based malware detection.
- [[Application Allowlisting]] — Only pre-approved binaries may execute.
- [[Container Security]] — Image scanning, runtime protection, admission control for Docker/Kubernetes workloads.
- [[DLP]] — Data Loss Prevention.
- [[EDR]] — Endpoint Detection and Response.
- [[EPP]] — Endpoint Protection Platform.
- [[Hardening]] — Reducing attack surface by disabling unused features, enforcing baselines (CIS Benchmarks), patching.
- [[HIDS and HIPS]] — Host-based Intrusion Detection / Prevention.
- [[MDR]] — Managed Detection and Response.
- [[Patch Management]] — Process of testing and deploying vendor fixes.
- [[Sandbox]] — Isolated execution environment used to analyze suspicious files or run untrusted code safely.
- [[XDR]] — Xtended Detection and Response.

# Cloud & Modern Architecture

> A new layer of vocabulary that mostly renames old ideas for elastic, API-driven environments. The acronyms ending in PM (CSPM, CIEM, KSPM, DSPM, SSPM) are a family — same posture-management idea applied to different surfaces.

## Terms in this domain

- [[CASB]] — Cloud Access Security Broker.
- [[CIEM]] — Cloud Infrastructure Entitlement Management.
- [[CNAPP]] — Cloud-Native Application Protection Platform.
- [[Confidential Computing]] — Processing data in hardware-isolated TEEs (Trusted Execution Environments).
- [[Control Plane]] — Management/API surface.
- [[CSPM]] — Cloud Security Posture Management.
- [[CWPP]] — Cloud Workload Protection Platform.
- [[eBPF]] — Linux kernel technology enabling deep observability and security tooling with low overhead (Cilium, Falco).
- [[IaaS PaaS SaaS]] — Infrastructure / Platform / Software as a Service.
- [[IMDS]] — Instance Metadata Service.
- [[KSPM]] — Kubernetes Security Posture Management.
- [[SASE]] — Secure Access Service Edge.
- [[Service Mesh]] — Network layer for service-to-service communication (Istio, Linkerd), often providing mTLS and policy by default.
- [[Shared Responsibility Model]] — Cloud provider secures *of* the cloud; customer secures *in* the cloud.
- [[Sidecar]] — Helper container deployed alongside a workload, often providing security/observability.
- [[SSE]] — Security Service Edge.
- [[SWG]] — Secure Web Gateway.
- [[Tenant]] — Logical isolation of customers sharing infrastructure.
- [[ZTNA]] — Zero Trust Network Access.

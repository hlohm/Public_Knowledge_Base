# SecOps, Detection & Response

> The daily-life vocabulary of a SOC analyst. The pipeline runs: signal → detection → triage → investigation → response → lessons learned.

## Terms in this domain

- [[Adversary Emulation]] — Simulating a specific real-world threat actor's TTPs (CALDERA, Atomic Red Team).
- [[Beacon]] — Persistent agent that calls home periodically to receive commands.
- [[C2]] — Command and Control (also C&C).
- [[Chain of Custody]] — Documentation trail proving evidence integrity.
- [[Cyber Kill Chain]] — Lockheed Martin's 7-phase intrusion model: Recon → Weaponization → Delivery → Exploitation → Installation → C2 → Actions on Objectives.
- [[Detection Engineering]] — The discipline of building and maintaining detections, including testing them with adversary emulation.
- [[DFIR]] — Digital Forensics and Incident Response.
- [[Dwell Time]] — Duration attacker was present before detection.
- [[False Positive]] — Alert that wasn't a real attack.
- [[Incident Response]] — Coordinated action to contain and recover from an incident.
- [[IOA]] — Indicator of Attack.
- [[IOC]] — Indicator of Compromise.
- [[MITRE ATT&CK]] — Knowledge base of adversary TTPs, organized by tactic (the why) and technique (the how).
- [[MTTD and MTTR]] — Mean Time to Detect / Respond.
- [[Playbook]] — Documented response procedure.
- [[Post-Mortem]] — Blameless analysis after an incident.
- [[Purple Team]] — Collaborative offense + defense exercises designed to *improve detections*, not just score wins.
- [[Pyramid of Pain]] — David Bianco's model: the higher up the indicator type, the more painful for the attacker to change.
- [[SIEM]] — Security Information and Event Management.
- [[SOAR]] — Security Orchestration, Automation, and Response.
- [[SOC]] — Security Operations Center.
- [[Tabletop Exercise]] — Discussion-based scenario walkthrough to test plans without touching production.
- [[Threat Hunting]] — Proactively searching for threats that evade automated detection.
- [[Threat Intelligence]] — Knowledge about adversaries, used to prioritize defenses.
- [[TTPs]] — Tactics, Techniques, and Procedures.

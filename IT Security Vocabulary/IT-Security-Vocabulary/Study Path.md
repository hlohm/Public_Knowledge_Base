# Study Path

Build fluency in roughly this order — it scaffolds best:

1. [[01 - Core Principles]] + [[02 - Risk and Governance]] — the grammar.
2. [[03 - Cryptography]] + [[04 - Identity and Access Management]] — the building blocks every other domain reuses.
3. [[05 - Network Security]] + [[06 - Endpoint and Host Security]] — the classic perimeter view.
4. [[07 - Threats and Attacks]] + [[09 - Vulnerabilities and Exposure]] — what you're defending against, plus how the industry talks about it.
5. [[08 - Application Security]] — where most modern bugs are born.
6. [[10 - Cloud and Modern Architecture]] — re-skinning of all the above for elastic infrastructure.
7. [[11 - SecOps Detection and Response]] — daily operations, where everything converges.
8. [[12 - Offensive Security and Testing]] + [[13 - Compliance and Standards]] — the two mirrors: attacker and auditor.

## Daily study loop

1. Pick a term you don't fully know.
2. Read its note.
3. Follow 2–3 `[[See also]]` links — read those too.
4. Open Graph View (Ctrl/Cmd-G) and look at the cluster.
5. If you encountered the term in the real world, capture *where* you saw it in the note as a comment — context aids recall.

## Reinforce with active recall

Add the Spaced Repetition community plugin (see Obsidian guide). Tag a term `#flashcard` and write the prompt as a question on the first line; Obsidian will quiz you.

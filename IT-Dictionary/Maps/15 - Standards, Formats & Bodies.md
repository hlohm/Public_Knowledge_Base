# Standards, Formats & Bodies

> The organisations and specifications that keep the field interoperable — IETF, IEEE, ISO, Unicode, W3C.

## Terms in this branch (10)

- [[Backward Compatibility]] — The property that newer versions of a system, format, or interface continue to work with inputs, data, or clients built for older versions.
- [[ECMA]] — A standards body best known in software for ECMAScript (ECMA-262) — the standardised core that JavaScript implements — and JSON (ECMA-404).
- [[IEEE]] — A major professional body and standards organisation behind foundational technical standards — Ethernet (802.3), Wi-Fi (802.11), and floating-point arithmetic (754).
- [[IETF]] — The open, volunteer standards body that develops and publishes the internet's core technical standards (as RFCs) — TCP/IP, HTTP, TLS, DNS.
- [[Interoperability]] — The ability of different systems or implementations to work together by adhering to shared standards and formats.
- [[ISO]] — The international standards body publishing standards across virtually every field — including ones you meet constantly: ISO 8601 (dates), ISO/IEC 27001 (infosec management), C and C++ language standards.
- [[NIST]] — A US agency whose standards carry global weight in computing security — the AES and SHA cryptographic standards, the post-quantum crypto selections, and the Cybersecurity Framework.
- [[Open Standard]] — A specification that is publicly available and free (or fairly) to implement, typically developed through an open, consensus process — HTTP, HTML, PDF, TCP/IP.
- [[RFC]] — A numbered document in the series that defines internet protocols and conventions — HTTP, TCP, IP, SMTP, and the rest of the internet's standards live here.
- [[W3C]] — The main standards body for the web — HTML, CSS, the DOM, accessibility (WCAG) — developing 'Recommendations' that browsers implement.

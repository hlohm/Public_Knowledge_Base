# Threats & Attacks

> The verbs and adversaries of the language. Each is worth being able to describe in one sentence.

## Terms in this domain

- [[APT]] — Advanced Persistent Threat.
- [[BEC]] — Business Email Compromise.
- [[Botnet]] — Network of compromised hosts ('zombies') under attacker control.
- [[Brute Force]] — Trying many passwords or keys.
- [[Buffer Overflow]] — Writing past allocated memory, corrupting adjacent data or control flow.
- [[CSRF]] — Cross-Site Request Forgery.
- [[DDoS]] — Distributed Denial of Service (or plain DoS).
- [[Directory Traversal]] — `../../../etc/passwd` and friends.
- [[Exfiltration]] — Getting stolen data out.
- [[Injection Attacks]] — Tricking an interpreter into running attacker-controlled input: SQL injection, command injection, LDAP injection, NoSQL injection, prompt injection.
- [[Jailbreak]] — Defeating a system's built-in restrictions as its own user (device lockdown, or an LLM's safety refusals).
- [[Lateral Movement]] — Moving from initial foothold to other systems inside the network.
- [[Lethal Trifecta]] — Private data + untrusted content + external communication: the combination that turns an AI agent into an exfiltration machine.
- [[LotL]] — Living off the Land.
- [[Malware]] — Umbrella term for malicious software: virus, worm, trojan, rootkit, bootkit, spyware, adware, bot, ransomware, wiper, dropper/loader.
- [[MITM]] — Man-In-The-Middle (also AitM = Adversary-in-the-Middle).
- [[N-Day]] — Known and patched vuln still being exploited against unpatched systems.
- [[Pass-the-Hash]] — Reusing stolen credentials/hashes in Windows environments without ever knowing the password.
- [[Password Spraying]] — Trying a few common passwords against many accounts (evades lockouts).
- [[Persistence]] — Maintaining access across reboots and credential changes.
- [[Phishing]] — Social engineering via message to trick users into clicking, opening, or revealing.
- [[Prompt Injection]] — Planting instructions in content an LLM processes so it follows the attacker instead of its operator.
- [[Ransomware]] — Encrypts data and demands payment.
- [[RAT]] — Remote Access Trojan.
- [[RCE]] — Remote Code Execution.
- [[Replay Attack]] — Capturing valid data and resending it to gain unauthorized effect.
- [[Rootkit]] — Malware that hides itself and other malware at deep OS or firmware level.
- [[Session Fixation]] — Planting a session ID the attacker knows, then riding the session once the victim logs into it.
- [[Session Hijacking]] — Stealing an authenticated session's ID (usually the cookie) and presenting it as your own.
- [[Smishing and Vishing]] — SMS and voice variants of phishing.
- [[Social Engineering]] — Manipulating people rather than systems.
- [[Spear Phishing]] — Phishing targeted at a specific individual, usually after research.
- [[SSRF]] — Server-Side Request Forgery.
- [[Supply Chain Attack]] — Compromising a vendor, dependency, or build pipeline to reach downstream targets (SolarWinds, log4j, XZ Utils).
- [[Traffic Correlation Attack]] — Matching traffic at both ends to deanonymise a low-latency network.
- [[Trojan]] — Malicious payload disguised as legitimate software.
- [[Virus]] — Self-replicating code requiring a host file and user action.
- [[Watering Hole]] — Compromising a site the target frequents.
- [[Whaling]] — Spear-phishing targeted at executives.
- [[Wiper]] — Pretends to be ransomware but destroys data with no recovery option.
- [[Worm]] — Self-propagating across networks without user action.
- [[XSS]] — Cross-Site Scripting.
- [[Zero Day]] — Vulnerability unknown to the vendor (and therefore unpatched).

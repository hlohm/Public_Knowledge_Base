# Vulnerabilities & Exposure

> A small ecosystem of identifiers and scoring systems that lets the industry talk about specific weaknesses precisely: CVE, CWE, CVSS, EPSS, KEV.

## Terms in this domain

- [[Bug Bounty]] — Program paying external researchers for valid vulnerability reports.
- [[Coordinated Disclosure]] — Researcher reports vuln to vendor, agrees on timeline before public release.
- [[CVE]] — Common Vulnerabilities and Exposures.
- [[CVSS]] — Common Vulnerability Scoring System.
- [[CWE]] — Common Weakness Enumeration.
- [[EPSS]] — Exploit Prediction Scoring System.
- [[Full Disclosure]] — Publishing vulnerability details immediately, with or without vendor cooperation.
- [[KEV]] — CISA's Known Exploited Vulnerabilities catalog.
- [[Patch Tuesday]] — Microsoft's monthly security update cadence.
- [[Penetration Test]] — Authorized simulated attack to find exploitable weaknesses.
- [[Vulnerability Management]] — End-to-end process: scan → triage → prioritize → remediate → verify.
- [[Vulnerability Scanner]] — Tool that probes systems for known weaknesses (Nessus, Qualys, OpenVAS).

# Offensive Security & Testing

> The mirror image of defense. Useful vocabulary even if you never wear a black hoodie.

## Terms in this domain

- [[Blue Team]] — The defenders.
- [[C2 Framework]] — Tooling for managing implants (Cobalt Strike, Sliver, Mythic, Metasploit).
- [[CTF]] — Capture the Flag.
- [[Enumeration]] — Active probing for services, users, shares, etc.
- [[OSINT]] — Open-Source Intelligence.
- [[Payload]] — The code the exploit delivers and runs.
- [[Pivoting]] — Using a compromised host as a launchpad to reach others.
- [[Red Team]] — Goal-oriented adversary simulation, usually longer and stealthier than a pentest, measuring the blue team's detection and response.
- [[Reverse Shell]] — Reverse: target connects back to attacker (firewall-friendly).
- [[Shellcode]] — Small, position-independent payload, often spawning a shell.

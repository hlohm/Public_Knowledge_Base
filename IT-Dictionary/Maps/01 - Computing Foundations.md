# Computing Foundations

> The bedrock concepts every other branch leans on: bits, encodings, abstraction, the von Neumann model.

## Terms in this branch (25)

- [[Abstraction]] — Hiding detail behind a simpler interface so you can reason about a system without holding all of it in your head at once.
- [[ASCII]] — A 7-bit character encoding mapping 128 codes to English letters, digits, punctuation and control characters.
- [[Binary]] — The base-2 number system, using only 0 and 1 — the native language of digital hardware because a wire is either energised or not.
- [[Bit]] — The smallest unit of information: a single binary digit, 0 or 1.
- [[Byte]] — A group of (almost always) 8 bits — the smallest individually addressable unit of memory on most machines.
- [[Checksum]] — A small value computed from a block of data so that accidental corruption can be detected by recomputing and comparing.
- [[Code Point]] — A single number in a character set, e.g.
- [[Endianness]] — The order in which a multi-byte value's bytes are stored in memory.
- [[Epoch]] — The fixed zero-point a timekeeping scheme counts from.
- [[Floating Point]] — A representation of real numbers as a sign, a mantissa and an exponent — like scientific notation in binary.
- [[Flynn's Taxonomy]] — The standard classification of computer architectures by how many instruction streams and data streams operate concurrently: SISD, SIMD, MISD, and MIMD.
- [[Hexadecimal]] — Base-16 notation (digits 0–9 then A–F).
- [[Idempotent]] — An operation that has the same effect whether applied once or many times.
- [[IEEE 754]] — The standard that defines how floating-point numbers are stored and how their arithmetic behaves, including special values like ±∞ and NaN.
- [[Integer Overflow]] — What happens when an arithmetic result exceeds the range a fixed-width integer can hold — it wraps around (or, in some languages, is undefined behaviour).
- [[ISO 8601]] — The international standard date/time format, e.g.
- [[Message Passing]] — A parallelism model in which processes with separate, private memories cooperate by explicitly sending and receiving messages.
- [[Null]] — A special value meaning 'no value' or 'points to nothing'.
- [[Serialization]] — Converting an in-memory object or data structure into a flat byte stream (JSON, Protocol Buffers, etc.) that can be stored or sent, and back again (deserialization).
- [[Shared Memory]] — A parallelism model in which multiple processors cooperate by reading and writing a single common address space; coordination happens through memory itself — loads, stores, locks, atomics.
- [[Two's Complement]] — The standard way to represent signed integers in binary: negate by inverting all bits and adding one.
- [[Unicode]] — A universal character set assigning a unique number (code point) to virtually every character in every writing system, plus emoji and symbols.
- [[Unix Time]] — Time represented as the number of seconds elapsed since 00:00:00 UTC on 1 January 1970 (the 'epoch'), ignoring leap seconds.
- [[UTF-8]] — A variable-width encoding of Unicode using 1–4 bytes per code point.
- [[Word]] — The natural unit of data for a CPU — the register width and the size it moves and computes in one step.

# Finite State Machine

> **Branch:** [[10 - Theory of Computation|Theory of Computation]]
> **Also known as:** FSM, Finite Automaton

A computational model with a finite number of states and transitions triggered by inputs — no memory beyond the current state.

**Context.** Far more practical than its theory billing: protocol handlers, UI flows, regex engines, lexers, and game AI are all FSMs. The limit (finite memory, can't count arbitrarily) is exactly why it can't match balanced parentheses — the reason regular expressions can't parse HTML.

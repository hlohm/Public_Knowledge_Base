# Context-free Grammar

> **Branch:** [[10 - Theory of Computation|Theory of Computation]]
> **Also known as:** CFG

A set of production rules powerful enough to describe nested, recursive structure (balanced brackets, arithmetic expressions) — recognised by a pushdown automaton.

**Context.** The formalism behind nearly every programming language's syntax and the parsers that read it. One step up the Chomsky hierarchy from regular languages — the added power (a stack) is precisely what lets it handle nesting that regex cannot.

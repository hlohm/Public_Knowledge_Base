# CASB

> **Domain:** [[10 - Cloud and Modern Architecture|Cloud & Modern Architecture]]
> **Also known as:** Cloud Access Security Broker, "Shadow IT"

**C**loud **A**ccess **S**ecurity **B**roker. Sits between users and cloud apps, enforcing policy and giving visibility into SaaS usage (incl. **shadow IT**).

**Context.** The questions it answers: which SaaS do our people actually use (shadow-IT discovery from proxy/firewall logs), and can we enforce policy inside the sanctioned ones (API mode) or inline (proxy mode). In the Microsoft world this is Defender for Cloud Apps; the discovery report alone usually surprises management.

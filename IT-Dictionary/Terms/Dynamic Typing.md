# Dynamic Typing

> **Branch:** [[07 - Programming Languages|Programming Languages]]

Type checking performed at runtime — a variable's type is a property of its current value, not a fixed declaration.

**Context.** Fast to write and flexible (Python, Ruby, JavaScript), at the cost of type errors surfacing only when that code path runs. The industry's partial answer: gradual typing (type hints, TypeScript) bolting optional static checking onto dynamic languages.

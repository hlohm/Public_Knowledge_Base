# OSI Model

> **Branch:** [[04 - Networking|Networking]]

A 7-layer reference model (Physical, Data Link, Network, Transport, Session, Presentation, Application) for reasoning about network functions.

**Context.** More teaching tool than implementation map — the real stack is TCP/IP's 4-ish layers. Still the shared vocabulary: 'a layer-7 firewall', 'an L2 switch', 'works at layer 3'.

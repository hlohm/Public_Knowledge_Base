# Unit Test

> **Branch:** [[08 - Software Engineering|Software Engineering]]

An automated test exercising one small unit (a function/class) in isolation, fast and deterministic, verifying behaviour against expectations.

**Context.** The base of the test pyramid — many fast unit tests, fewer integration, fewest end-to-end. Isolation often needs test doubles (mocks, stubs). The real payoff is regression safety and the design pressure: hard-to-test code is usually badly-coupled code.

# Halting Problem

> **Branch:** [[10 - Theory of Computation|Theory of Computation]]
> **German:** Halteproblem

The problem of deciding, for an arbitrary program and input, whether it will eventually halt or run forever — proven by Turing to be **undecidable**: no general algorithm can solve it for all cases.

**Context.** The foundational impossibility result, and a practical ceiling, not just a curiosity: it's *why* perfect static analysis, exhaustive bug detection, and total termination checking can't exist in general. Many real questions reduce to it (Rice's theorem generalises the gloom to all non-trivial semantic properties).

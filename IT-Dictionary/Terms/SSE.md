# SSE

> **Domain:** [[10 - Cloud and Modern Architecture|Cloud & Modern Architecture]]
> **Also known as:** Security Service Edge

**S**ecurity **S**ervice **E**dge. The security half of SASE without the SD-WAN.

**Context.** The practical entry point for most orgs: adopt the security services (SWG, CASB, ZTNA) from the cloud while leaving WAN architecture alone — SASE minus SD-WAN. Vendor shortlists here look like Zscaler, Netskope, Cloudflare, Microsoft's Entra Internet/Private Access.

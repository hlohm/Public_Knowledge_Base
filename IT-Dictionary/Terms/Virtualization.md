# Virtualization

> **Branch:** [[11 - Cloud & Infrastructure|Cloud & Infrastructure]]
> **German:** Virtualisierung

Abstracting physical hardware into multiple isolated virtual instances, so one machine runs many independent operating systems or environments.

**Context.** The foundation the entire cloud is built on — it's what lets a provider slice one big server among many tenants. The lineage runs hardware virtualization (full VMs) → OS-level virtualization (containers) → functions, each lighter and faster to start than the last.

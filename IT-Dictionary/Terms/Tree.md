# Tree

> **Branch:** [[09 - Algorithms & Data Structures|Algorithms & Data Structures]]
> **German:** Baum

A hierarchical structure of nodes with a single root, where each node has children but exactly one parent — no cycles.

**Context.** The shape of hierarchy everywhere: filesystems, the DOM, ASTs, org charts, decision trees. Balanced search trees give O(log n) operations; the difference between a balanced and a degenerate (linked-list-shaped) tree is the whole game.

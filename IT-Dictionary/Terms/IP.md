# IP

> **Branch:** [[04 - Networking|Networking]]
> **Also known as:** Internet Protocol

The network-layer protocol that addresses and routes packets across interconnected networks, best-effort and connectionless.

**Context.** Everything above (TCP, UDP) rides on IP's unreliable delivery; reliability is layered on top, not built in.

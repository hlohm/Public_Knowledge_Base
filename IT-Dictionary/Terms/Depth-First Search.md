# Depth-First Search

> **Branch:** [[09 - Algorithms & Data Structures|Algorithms & Data Structures]]
> **Also known as:** DFS

A graph traversal that explores as far as possible down one branch before backtracking, using a stack or recursion.

**Context.** The basis of topological sort, cycle detection, connected components, and most backtracking. Lower memory than BFS on wide graphs, but doesn't find shortest paths. The recursive form is elegant; watch the stack depth on deep graphs.

# Functional Programming

> **Branch:** [[07 - Programming Languages|Programming Languages]]
> **Also known as:** FP

Programming with [[Pure Function]]s and immutable data: computation as expression evaluation rather than state mutation. Functions are first-class values — passed, returned, composed.

**Context.** FP's bet is that forbidding [[Side Effect]]s makes code easier to reason about, test, and parallelize (no shared mutable state, no race conditions by construction). The ideas won even where the languages didn't: map/filter/reduce, immutability-by-default, and lambdas are now standard equipment in Java, Python, and JavaScript. Haskell is the pure reference point; most practice is hybrid.

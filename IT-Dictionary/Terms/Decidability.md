# Decidability

> **Branch:** [[10 - Theory of Computation|Theory of Computation]]

A problem is **decidable** if an algorithm exists that always halts with a correct yes/no answer; **undecidable** if no such algorithm can exist for all inputs.

**Context.** The sharp line between 'a computer can in principle solve this' and 'no it can't, ever'. The halting problem is the canonical undecidable one. Distinct from intractable (decidable but too slow, like NP-hard) — undecidable means *impossible*, not just expensive.

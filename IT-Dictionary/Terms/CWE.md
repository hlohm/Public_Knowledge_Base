# CWE

> **Domain:** [[09 - Vulnerabilities and Exposure|Vulnerabilities & Exposure]]
> **Also known as:** Common Weakness Enumeration

**C**ommon **W**eakness **E**numeration. Catalog of *weakness types* (e.g. CWE-79 = XSS).

**Context.** Where CVE names an *instance*, CWE names the *class* — CWE-79 is XSS, CWE-89 is SQLi — which makes it the right tool for finding patterns ("we keep shipping CWE-89, fix it at the framework level") rather than chasing individual bugs. The CWE Top 25 is a useful counterpart to the OWASP Top 10 for prioritizing which weakness classes to engineer out.

# Pixel

> **Branch:** [[14 - Graphics, Media & HCI|Graphics, Media & HCI]]
> **Also known as:** Picture Element

The smallest addressable element of a raster image or display — a single point, usually carrying colour as RGB (and sometimes alpha) values.

**Context.** The atom of digital imaging. Worth distinguishing from a device's physical subpixels and from the logical 'CSS pixel', which on high-DPI ('Retina') screens maps to several physical pixels — the device pixel ratio that constantly trips up web layout.

# Tabletop Exercise

> **Domain:** [[11 - SecOps Detection and Response|SecOps, Detection & Response]]

Discussion-based scenario walkthrough to test plans without touching production.

**Context.** The cheapest incident-response improvement there is: gather the responders (including legal, comms, and a management decision-maker), walk a realistic scenario, and watch the gaps surface — who has authority to pull the plug, where's the contact list, how do we talk if email is down. The value is in the awkward pauses. Run them before you need them, not after.

# Operating System

> **Branch:** [[03 - Operating Systems|Operating Systems]]
> **Also known as:** OS
> **German:** Betriebssystem

The software layer that manages hardware and provides services — scheduling, memory, files, devices, security — so programs can run without each reinventing them.

**Context.** Its two big jobs are *abstraction* (a uniform interface over messy hardware) and *arbitration* (safely sharing finite resources among competing processes). The German *Betriebssystem* is the standard word.

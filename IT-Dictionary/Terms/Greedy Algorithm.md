# Greedy Algorithm

> **Branch:** [[09 - Algorithms & Data Structures|Algorithms & Data Structures]]

An algorithm that makes the locally optimal choice at each step, hoping to reach a global optimum.

**Context.** Beautifully simple and fast *when it works* — and proving it works (that local optima compose into a global one) is the catch. Correct for some problems (Dijkstra, Huffman, minimum spanning trees), wrong for others (the greedy knapsack), where DP is needed instead.

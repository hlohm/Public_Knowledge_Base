# Red Team

> **Domain:** [[12 - Offensive Security and Testing|Offensive Security & Testing]]

Goal-oriented adversary simulation, usually longer and stealthier than a pentest, measuring the blue team's detection and response.

**Context.** Not a thorough vulnerability sweep but a goal ("reach the crown-jewel data," "prove domain compromise") pursued stealthily over weeks — the real test is whether the blue team *notices*. That makes it a measure of detection and response maturity, expensive, and wasted on an org that hasn't done the basics (it'll just confirm the obvious). Crawl with a pentest, walk with purple teaming, run with red.

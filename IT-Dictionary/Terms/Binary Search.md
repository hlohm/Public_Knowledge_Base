# Binary Search

> **Branch:** [[09 - Algorithms & Data Structures|Algorithms & Data Structures]]

Finding an element in a *sorted* array in O(log n) by repeatedly halving the search interval.

**Context.** Deceptively easy to get wrong (off-by-one, overflow in the midpoint) — famously, most hand-written implementations have bugs. The general technique ('binary search on the answer') solves far more than array lookup: any monotonic predicate over a range.

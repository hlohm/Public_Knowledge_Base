# SASE

> **Domain:** [[10 - Cloud and Modern Architecture|Cloud & Modern Architecture]]
> **Also known as:** Secure Access Service Edge

**S**ecure **A**ccess **S**ervice **E**dge. Cloud-delivered combo of networking (SD-WAN) and security (SWG, CASB, ZTNA, FWaaS). Pronounced 'sassy'.

**Context.** The architectural bet: with users remote and apps in SaaS, backhauling traffic to a datacenter firewall stopped making sense — so the security stack moves to cloud POPs that users connect to from anywhere. Adoption reality: it's a multi-year network *and* security re-architecture, usually arriving piecewise via ZTNA-first or SWG-first projects.

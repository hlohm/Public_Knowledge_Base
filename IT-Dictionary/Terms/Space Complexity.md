# Space Complexity

> **Branch:** [[09 - Algorithms & Data Structures|Algorithms & Data Structures]]

How an algorithm's memory use scales with input size, in Big-O terms.

**Context.** The other half of the cost picture, and the constant tradeoff partner of time: memoisation and lookup tables buy speed with space; streaming and in-place algorithms save space at some time cost. In-place (O(1) extra space) is a prized property.

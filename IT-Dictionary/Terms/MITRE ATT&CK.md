# MITRE ATT&CK

> **Domain:** [[11 - SecOps Detection and Response|SecOps, Detection & Response]]
> **Also known as:** ATT&CK

Knowledge base of adversary TTPs, organized by **tactic** (the why) and **technique** (the how). The lingua franca of modern detection.

**Context.** The shared map everyone now points at: detection coverage ("which techniques can we see?"), threat-actor profiles, purple-team scoping, and tool comparisons all reference ATT&CK IDs (T1059, T1003…). Practical use is the Navigator heatmap — color your detection coverage, find the gaps, prioritize. It's a reference framework, not a maturity score; coverage of every technique is neither possible nor the goal.

# Virus

> **Domain:** [[07 - Threats and Attacks|Threats & Attacks]]

Self-replicating code requiring a host file and user action.

**Context.** The original term, now often used loosely for all malware, but technically specific: it needs a host file and a user to execute it, spreading as those files are shared. Pure file-infecting viruses faded as distribution moved to networks, email, and the web — worms, droppers, and trojans fit the modern delivery model better.

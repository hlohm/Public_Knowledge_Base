# Latency

> **Branch:** [[04 - Networking|Networking]]
> **German:** Latenz

The time for one unit of data to travel from source to destination — a delay, measured in milliseconds.

**Context.** Bounded by physics (speed of light ≈ 5 µs/km in fibre), so it can't be 'bought away' like bandwidth. The metric users actually feel.

## See also

- [[Bandwidth]]
- [[Throughput]]
- [[Jitter]]

## Often confused with

- [[Bandwidth]] — Latency = delay of one trip; bandwidth = capacity. A fat, slow-to-respond pipe still feels laggy.

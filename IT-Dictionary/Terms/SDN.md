# SDN

> **Domain:** [[05 - Network Security|Network Security]]
> **Also known as:** Software-Defined Networking

**S**oftware-**D**efined **N**etworking. Separating the control plane from the data plane; enables programmable networks and microsegmentation.

**Context.** The security dividend is policy as code: network rules become API objects you can version, review, and audit, and microsegmentation becomes tractable. The new risk concentrates accordingly — the SDN controller is the network's domain admin, and its API credentials deserve PAM-grade handling.

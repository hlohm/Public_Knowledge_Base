# Secure by Design

> **Domain:** [[08 - Application Security|Application Security]]
> **Also known as:** Secure by Default

Security built into the architecture. **Secure by Default** means turned on out of the box.

**Context.** The shift CISA has been pushing onto vendors: safety shouldn't be the customer's configuration project. Concretely it means memory-safe languages, eliminating default passwords, MFA available without an upcharge, and shipping with the hardened settings on. "Secure by default" is its operational half — the out-of-box state is the one most deployments will live in forever.

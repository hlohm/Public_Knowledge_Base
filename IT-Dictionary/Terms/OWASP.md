# OWASP

> **Domain:** [[08 - Application Security|Application Security]]

**O**pen **W**orldwide **A**pplication **S**ecurity **P**roject. Nonprofit producing the canonical AppSec resources.

**Context.** The default free toolbox for application security: the Top 10 for awareness, the Cheat Sheet Series for how-to, ASVS for verification requirements, ZAP for testing, and dependency-check for SCA. When someone asks "where do I start with web security," the honest answer is usually a specific OWASP page.

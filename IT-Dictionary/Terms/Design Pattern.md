# Design Pattern

> **Branch:** [[08 - Software Engineering|Software Engineering]]
> **German:** Entwurfsmuster

A named, reusable solution to a recurring design problem — a shared vocabulary (Singleton, Observer, Factory, Strategy) rather than copy-paste code.

**Context.** The Gang of Four catalogued the originals. Value lies more in the shared vocabulary than in rote application; some patterns are partly workarounds for missing language features (the Strategy pattern is just a first-class function elsewhere). Reach for them to *name* a solution you've arrived at, not to force structure.

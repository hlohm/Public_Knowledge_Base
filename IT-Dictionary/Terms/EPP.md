# EPP

> **Domain:** [[06 - Endpoint and Host Security|Endpoint & Host Security]]
> **Also known as:** Endpoint Protection Platform

**E**ndpoint **P**rotection **P**latform. Modern AV: signatures + heuristics + behavioral + ML.

**Context.** EPP is the prevention layer, EDR the visibility layer — vendors sell them as one agent, and the market has converged so far that the distinction is mostly historical. The practical evaluation criteria: detection quality in independent tests (AV-Comparatives, MITRE ATT&CK evals), performance impact, and how tamper-resistant the agent is.

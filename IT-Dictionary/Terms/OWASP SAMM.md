# OWASP SAMM

> **Domain:** [[08 - Application Security|Application Security]]
> **Also known as:** Software Assurance Maturity Model

**S**oftware **A**ssurance **M**aturity **M**odel. Framework for assessing and improving an org's secure-development practice.

**Context.** The program-maturity lens: it scores your secure-development practices across governance, design, implementation, verification, and operations, so you can target the weakest function instead of buying another scanner. Complements BSIMM (which describes what firms *do*) — SAMM prescribes what to *improve*.

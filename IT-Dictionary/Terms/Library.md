# Library

> **Branch:** [[08 - Software Engineering|Software Engineering]]
> **German:** Bibliothek

A collection of reusable code you call from your program — *you* control the flow and call into it.

**Context.** The inversion-of-control distinction from a framework is the thing worth knowing: with a library you're in charge and call it; with a framework, it's in charge and calls you ('don't call us, we'll call you').

# RDBMS

> **Branch:** [[06 - Data & Databases|Data & Databases]]
> **Also known as:** Relational Database Management System, Relational Database

A database organising data into **relations** (tables of rows and columns) with enforced schemas and relationships, queried with SQL.

**Context.** The default choice for fifty years for good reason: the relational model (Codd, 1970) gives a clean mathematical foundation, and ACID transactions make correctness the engine's problem rather than yours. Postgres, MySQL, Oracle, SQL Server are the household names.

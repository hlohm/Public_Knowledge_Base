# CI

> **Branch:** [[08 - Software Engineering|Software Engineering]]
> **Also known as:** Continuous Integration

The practice of merging all developers' work to a shared mainline frequently, with each integration automatically built and tested.

**Context.** The point is *frequency*: integrate small changes often so conflicts and breakages stay tiny and are caught in minutes. A running CI server is the enforcement mechanism. The natural partner to trunk-based development.

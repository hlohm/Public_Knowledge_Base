# Static Typing

> **Branch:** [[07 - Programming Languages|Programming Languages]]

Type checking performed at compile time — types are known and verified before the program runs.

**Context.** Catches type errors before deployment and gives the compiler information for optimisation and tooling (autocomplete, refactoring). The tradeoff against dynamic typing is ceremony and flexibility vs. early safety; type inference (below) softens the verbosity.

## Often confused with

- [[Dynamic Typing]] — Static = types checked at compile time; dynamic = types checked at runtime. Orthogonal to strong/weak.

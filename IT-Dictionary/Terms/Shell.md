# Shell

> **Branch:** [[03 - Operating Systems|Operating Systems]]

A program that interprets your commands and runs other programs — the text interface to the OS. bash, zsh, PowerShell are shells.

**Context.** It's called a 'shell' because it wraps the kernel. Beyond running commands it's a small programming language (variables, loops, pipes), which is what makes shell scripting both powerful and a frequent source of injection bugs.

# Binary

> **Branch:** [[01 - Computing Foundations|Computing Foundations]]
> **Also known as:** Base 2
> **German:** Binärsystem

The base-2 number system, using only 0 and 1 — the native language of digital hardware because a wire is either energised or not.

**Context.** Counting in binary, each position is a power of two; this is why memory sizes cluster on powers of two (256, 1024, 65536).

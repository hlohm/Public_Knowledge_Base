# Git

> **Branch:** [[08 - Software Engineering|Software Engineering]]

The dominant distributed version control system — a content-addressed store of immutable snapshots, where branches are cheap movable pointers into a commit DAG.

**Context.** The mental model that makes Git click: it's a DAG of commits, each a snapshot identified by a hash; branches and tags are just labels on commits; the index/staging area is the third state between working tree and history. Once that lands, the commands stop feeling arbitrary.

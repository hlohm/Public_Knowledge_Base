# Trojan

> **Domain:** [[07 - Threats and Attacks|Threats & Attacks]]

Malicious payload disguised as legitimate software.

**Context.** The delivery trick, not a capability — "useful" software (a cracked app, a fake installer, a malicious macro doc) that smuggles a payload. Survives because it exploits intent rather than a bug, and the modern twist is trojanized legitimate software via supply-chain compromise. User caution helps; allowlisting and EDR help more.

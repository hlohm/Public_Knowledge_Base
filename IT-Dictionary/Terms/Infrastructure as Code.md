# Infrastructure as Code

> **Branch:** [[11 - Cloud & Infrastructure|Cloud & Infrastructure]]
> **Also known as:** IaC

Defining and provisioning infrastructure through machine-readable definition files rather than manual setup — infrastructure managed like source code.

**Context.** The shift that made infrastructure reproducible, reviewable, and version-controlled: no more snowflake servers built by hand and undocumented. Declarative tools (Terraform) describe desired state; the distinction between declarative and imperative IaC is the key design axis.

# Deep Learning

> **Branch:** [[13 - AI & Machine Learning|AI & Machine Learning]]

Machine learning using neural networks with many layers, which learn hierarchical feature representations directly from raw data.

**Context.** The breakthrough was eliminating manual feature engineering — the network learns its own features, low-level to high-level, layer by layer. What made it finally work: lots of data, GPU compute, and architectural tricks (ReLU, normalisation, attention). The engine behind the 2010s AI boom.

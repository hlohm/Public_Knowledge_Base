# Stack

> **Branch:** [[09 - Algorithms & Data Structures|Algorithms & Data Structures]]
> **German:** Stapel

A LIFO (last-in, first-out) collection: push to add, pop to remove from the same end.

**Context.** Everywhere: the call stack (function frames), expression evaluation, undo, backtracking, depth-first search. The abstract data type, distinct from 'the stack' (the call-stack region of memory) — though they're named for the same discipline.

- [[Queue]] — Stack is LIFO (last in, first out — like a stack of plates); queue is FIFO (first in, first out — like a line).

# Framework

> **Branch:** [[08 - Software Engineering|Software Engineering]]

A reusable scaffold that defines the structure of your application and calls *your* code at the points it specifies — inversion of control.

**Context.** More opinionated and more total than a library: it dictates architecture (Django, Rails, Spring, React). Picking one is a long-term commitment to its conventions and lifecycle. The tradeoff: speed and structure now vs. lock-in and 'fighting the framework' later.

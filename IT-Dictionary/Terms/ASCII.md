# ASCII

> **Branch:** [[01 - Computing Foundations|Computing Foundations]]
> **Also known as:** American Standard Code for Information Interchange

A 7-bit character encoding mapping 128 codes to English letters, digits, punctuation and control characters. The historical root of most text encodings.

**Context.** Its 128-code ceiling couldn't fit accented or non-Latin scripts, spawning a mess of incompatible 8-bit 'code pages' that Unicode eventually unified. ASCII survives as the first 128 code points of Unicode/UTF-8.

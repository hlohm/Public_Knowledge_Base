# CSPM

> **Domain:** [[10 - Cloud and Modern Architecture|Cloud & Modern Architecture]]
> **Also known as:** Cloud Security Posture Management

**C**loud **S**ecurity **P**osture **M**anagement. Continuously checks cloud config against best practices and compliance frameworks.

**Context.** Catches the breach class that dominates cloud incidents: not exploits, but configuration — public storage buckets, permissive security groups, disabled logging, unencrypted databases. Continuous checks against CIS benchmarks and compliance mappings, ideally wired to auto-remediate the unambiguous cases. Free tier: the cloud providers' own tools (Defender for Cloud, AWS Security Hub) cover the basics.

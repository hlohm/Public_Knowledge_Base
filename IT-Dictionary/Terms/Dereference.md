# Dereference

> **Branch:** [[07 - Programming Languages|Programming Languages]]

Following a pointer or reference to access the value it points to.

**Context.** The act where things go wrong: dereferencing null or a freed pointer is undefined behaviour in C/C++ and a crash (or worse, a vulnerability) elsewhere. The `*` in C, the implicit follow in most managed languages.

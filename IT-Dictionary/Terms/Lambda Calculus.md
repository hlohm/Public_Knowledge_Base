# Lambda Calculus

> **Branch:** [[10 - Theory of Computation|Theory of Computation]]

A formal system of computation built entirely from function definition and application — Turing-complete using nothing but anonymous functions.

**Context.** Church's model, equivalent in power to Turing machines but functional rather than imperative. The theoretical bedrock of functional programming: lambdas, closures, currying, and type systems all trace back here. Proof that you can compute anything with just functions.

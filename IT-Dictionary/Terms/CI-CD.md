# CI/CD

> **Branch:** [[12 - DevOps & SRE|DevOps & SRE]]
> **Also known as:** Continuous Integration / Continuous Delivery

The automated pipeline from code commit to deployment — continuous integration (build + test every change) flowing into continuous delivery/deployment (automated release).

**Context.** The backbone of modern delivery. Note the CD ambiguity: continuous *delivery* keeps every change deployable with a manual release gate; continuous *deployment* removes even that, shipping to production automatically once tests pass.

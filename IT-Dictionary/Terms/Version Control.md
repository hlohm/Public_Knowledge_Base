# Version Control

> **Branch:** [[08 - Software Engineering|Software Engineering]]
> **Also known as:** VCS, Source Control
> **German:** Versionsverwaltung

A system that records changes to files over time so you can recall any version, branch, merge, and collaborate without overwriting each other's work.

**Context.** Distributed VCS (Git) won decisively over centralised (SVN, CVS): everyone has the full history, commits are local and cheap, branching is trivial. The conceptual model — a DAG of immutable snapshots — is worth understanding beneath the porcelain commands.

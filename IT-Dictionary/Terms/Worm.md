# Worm

> **Domain:** [[07 - Threats and Attacks|Threats & Attacks]]

Self-propagating across networks without user action.

**Context.** Self-propagation is the dangerous property — no user click, so spread is exponential and global within hours (WannaCry via EternalBlue, Conficker before it). The combination of a wormable RCE in a network service is the industry's worst-case scenario, which is why such CVEs (e.g. anything "wormable" in Microsoft's bulletins) trigger emergency patching. Internal segmentation limits how far one can travel.

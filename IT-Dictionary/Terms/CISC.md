# CISC

> **Branch:** [[02 - Hardware & Architecture|Hardware & Architecture]]
> **Also known as:** Complex Instruction Set Computer

A design with a large set of powerful, variable-length instructions, some doing whole operations (memory-to-memory add) in one step. x86 is the archetype.

**Context.** Born when memory was scarce and assembly was hand-written, so dense, capable instructions mattered. Today x86 keeps CISC's instruction encoding for compatibility but executes RISC-style internally.

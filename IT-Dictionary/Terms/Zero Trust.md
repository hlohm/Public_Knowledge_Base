# Zero Trust

> **Domain:** [[01 - Core Principles|Core Principles & Models]]
> **Also known as:** ZT

'Never trust, always verify.' Treat every request as if it originated from an untrusted network, regardless of location.

**Context.** Codified by NIST SP 800-207. Practical realization: identity-aware proxies, microsegmentation, continuous verification.

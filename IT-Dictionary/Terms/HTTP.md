# HTTP

> **Branch:** [[05 - Internet & Web|Internet & Web]]
> **Also known as:** Hypertext Transfer Protocol

The request/response application protocol of the web: a client asks for a resource with a method (GET, POST…), a server answers with a status code and body.

**Context.** It's *stateless* by design — each request is independent — so state (login) is bolted on via cookies/tokens. Understanding statelessness explains most of web architecture.

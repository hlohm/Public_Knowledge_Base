# Machine Learning

> **Branch:** [[13 - AI & Machine Learning|AI & Machine Learning]]
> **Also known as:** ML
> **German:** maschinelles Lernen

Building systems that learn patterns from data to make predictions or decisions, rather than following explicitly programmed rules.

**Context.** The fundamental inversion from traditional programming: instead of writing rules to produce answers, you feed in examples (data + answers) and the system *infers* the rules. The three broad paradigms — supervised, unsupervised, reinforcement — differ in what signal the data provides.

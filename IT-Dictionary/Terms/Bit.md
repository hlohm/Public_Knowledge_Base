# Bit

> **Branch:** [[01 - Computing Foundations|Computing Foundations]]
> **Also known as:** Binary Digit

The smallest unit of information: a single binary digit, 0 or 1. Every other quantity in computing is built from bits.

**Context.** The factor-of-8 trap lives here: link speeds are quoted in **bits** per second (Mb/s) but file sizes in **bytes** (MB), so a 100 Mb/s line moves ~12.5 MB/s, not 100.

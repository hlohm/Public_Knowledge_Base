# Instruction Set

> **Branch:** [[02 - Hardware & Architecture|Hardware & Architecture]]
> **Also known as:** ISA, Instruction Set Architecture

The contract between hardware and software: the set of instructions a CPU understands, its registers, and memory model. x86, ARM, and RISC-V are ISAs.

**Context.** The ISA is the stable interface that lets one binary run on many chip generations. It's distinct from microarchitecture — how a *specific* chip implements that ISA internally.

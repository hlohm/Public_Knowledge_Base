# HTML

> **Branch:** [[05 - Internet & Web|Internet & Web]]
> **Also known as:** HyperText Markup Language

**H**yper**T**ext **M**arkup **L**anguage. The document language of the web: nested elements describing structure and meaning, parsed by the browser into the [[DOM]]. Now a living standard maintained by WHATWG.

**Context.** HTML's superpower is forgiveness — the parser has defined error recovery for any garbage you feed it, which is why the web never broke but also why parsing it with regex is a famous fool's errand. The structure/presentation/behavior split (HTML/CSS/JavaScript) remains the architecture; semantic markup is what accessibility tooling and search engines actually consume.

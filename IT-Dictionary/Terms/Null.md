# Null

> **Branch:** [[01 - Computing Foundations|Computing Foundations]]

A special value meaning 'no value' or 'points to nothing'. Distinct from zero, empty string, or 'unknown'.

**Context.** Tony Hoare called inventing the null reference his 'billion-dollar mistake' for the crashes it caused. Modern languages fight back with option/maybe types, non-nullable references, and null-safety operators.

## Often confused with

- [[Undefined]] — Null is 'intentionally empty'; undefined is 'never assigned'. JavaScript exposes both.

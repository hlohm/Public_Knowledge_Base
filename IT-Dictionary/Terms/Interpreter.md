# Interpreter

> **Branch:** [[07 - Programming Languages|Programming Languages]]

A program that executes source code directly, translating and running it statement by statement rather than compiling to machine code first.

**Context.** Faster startup and easier debugging (no compile step), slower steady-state execution. The line is blurry: most 'interpreted' languages (Python, JS) compile to bytecode first, and JIT compilation makes the dichotomy a spectrum.

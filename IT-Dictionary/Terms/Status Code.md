# Status Code

> **Branch:** [[05 - Internet & Web|Internet & Web]]
> **Also known as:** HTTP Status Code

A three-digit number in an HTTP response signalling outcome: 2xx success, 3xx redirect, 4xx client error, 5xx server error.

**Context.** Using them correctly makes APIs debuggable and cacheable. Common confusions: 401 (unauthenticated) vs 403 (authenticated but forbidden); 401 means 'who are you?', 403 means 'no'.

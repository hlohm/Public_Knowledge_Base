# Error Budget

> **Branch:** [[12 - DevOps & SRE|DevOps & SRE]]

The amount of unreliability an SLO permits (100% minus the target), treated as a budget that can be 'spent' on risk, change, and feature velocity.

**Context.** The mechanism that turns reliability from a vague aspiration into a shared, quantitative decision: budget remaining → ship boldly; budget exhausted → freeze features and shore up reliability. It aligns dev (wants velocity) and ops (wants stability) on one number instead of arguing.

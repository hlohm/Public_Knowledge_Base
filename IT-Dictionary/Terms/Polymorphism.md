# Polymorphism

> **Branch:** [[07 - Programming Languages|Programming Languages]]

Code that operates on values of multiple types. The major kinds: **ad-hoc** (overloading), **parametric** (generics), and **subtype** (inheritance/interfaces).

**Context.** The word covers three quite different mechanisms that beginners conflate. Subtype polymorphism (a `Dog` used where an `Animal` is expected) is the OOP one; parametric is generics; ad-hoc is operator/function overloading. Knowing which is which clarifies a lot of language design.

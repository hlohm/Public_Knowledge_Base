# Monolith

> **Branch:** [[08 - Software Engineering|Software Engineering]]

An application built and deployed as a single unit, with all functionality in one codebase and process.

**Context.** Long a pejorative, now partly rehabilitated: a well-structured 'modular monolith' avoids distributed-systems pain and is the right default until scale forces otherwise. 'Start with a monolith, extract services when a seam genuinely hurts' is the current consensus.

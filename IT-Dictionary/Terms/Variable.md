# Variable

> **Branch:** [[07 - Programming Languages|Programming Languages]]

A named binding to a storage location or value. Whether it names a mutable box or an immutable value depends entirely on the language.

**Context.** The mutable-box mental model (C, Java) and the immutable-binding model (functional languages, Rust by default) diverge sharply, and the confusion when crossing languages is real. Scope and lifetime — where a name is visible and how long its value lives — are the deeper questions.

# CTF

> **Domain:** [[12 - Offensive Security and Testing|Offensive Security & Testing]]
> **Also known as:** Capture the Flag

**C**apture **t**he **F**lag. Hands-on cybersecurity competition. Jeopardy-style (challenges) or attack-defense.

**Context.** The on-ramp and the gym for offensive skills: Jeopardy CTFs are categorized puzzles (web, pwn, crypto, forensics, reversing), attack-defense pits teams against each other live. Platforms like Hack The Box and TryHackMe made the practice continuous. Real value for blue-teamers too — nothing builds attacker intuition like having to be one for a weekend.

# W3C

> **Branch:** [[15 - Standards, Formats & Bodies|Standards, Formats & Bodies]]
> **Also known as:** World Wide Web Consortium

The main standards body for the web — HTML, CSS, the DOM, accessibility (WCAG) — developing 'Recommendations' that browsers implement.

**Context.** Founded by Tim Berners-Lee. Its slow Recommendation process led the browser makers to spin out faster-moving efforts (WHATWG now owns the living HTML standard, TC39 owns JavaScript), so the web's standards are split across several bodies rather than one.

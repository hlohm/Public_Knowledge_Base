# Lambda

> **Branch:** [[07 - Programming Languages|Programming Languages]]
> **Also known as:** Anonymous Function, Lambda Expression

A function defined inline without a name, often passed as an argument — `x => x + 1`.

**Context.** Now ubiquitous (even Java and C++ have them), the workhorse of functional-style code: map/filter/reduce, callbacks, event handlers. Closely tied to closures, since lambdas usually capture their surrounding scope. Named after Church's lambda calculus.

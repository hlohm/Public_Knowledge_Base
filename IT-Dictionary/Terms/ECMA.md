# ECMA

> **Branch:** [[15 - Standards, Formats & Bodies|Standards, Formats & Bodies]]
> **Also known as:** Ecma International

A standards body best known in software for ECMAScript (ECMA-262) — the standardised core that JavaScript implements — and JSON (ECMA-404).

**Context.** Why the language is formally 'ECMAScript' and 'JavaScript' is the trademarked common name. The actual yearly evolution (ES2015 onward) runs through TC39, Ecma's technical committee, via a well-defined staged proposal process.

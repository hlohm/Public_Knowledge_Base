# Type System

> **Branch:** [[07 - Programming Languages|Programming Languages]]

The rules by which a language assigns and checks **types**, catching whole classes of errors and enabling optimisation. The system's power and where it checks (compile time vs runtime) define much of a language's character.

**Context.** A spectrum, not a binary: along static↔dynamic (when checked) and strong↔weak (how strictly). Rich static systems (Rust, Haskell, TypeScript) push more guarantees to compile time — 'make illegal states unrepresentable'. The cost is ceremony; the payoff is errors caught before they ship.

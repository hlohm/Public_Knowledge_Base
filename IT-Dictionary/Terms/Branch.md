# Branch

> **Branch:** [[08 - Software Engineering|Software Engineering]]

A divergent line of development. In Git, just a lightweight movable pointer to a commit — making branching and merging cheap.

**Context.** Branching *strategy* is the real topic: trunk-based development (short-lived branches, merge often) vs Git Flow (long-lived release branches). The industry has largely swung to trunk-based + feature flags to avoid painful long-lived merges.

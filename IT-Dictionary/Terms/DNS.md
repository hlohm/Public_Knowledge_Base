# DNS

> **Branch:** [[04 - Networking|Networking]]
> **Also known as:** Domain Name System

The distributed, hierarchical directory translating human names (example.com) into IP addresses and other records.

**Context.** Effectively a global cache with TTLs, which is why changes 'propagate' slowly. 'It's always DNS' is an ops cliché because it underlies almost everything and fails opaquely.

# RAM

> **Branch:** [[02 - Hardware & Architecture|Hardware & Architecture]]
> **Also known as:** Random Access Memory, Main Memory
> **German:** Arbeitsspeicher

Fast, volatile working memory the CPU reads and writes directly. 'Random access' means any location costs the same to reach, unlike tape or disk.

**Context.** Volatile = contents vanish on power loss, which is why work must be saved to non-volatile storage. The German *Arbeitsspeicher* ('working memory') is the everyday word; English 'RAM' is also understood.

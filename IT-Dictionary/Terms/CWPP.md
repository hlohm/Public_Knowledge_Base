# CWPP

> **Domain:** [[10 - Cloud and Modern Architecture|Cloud & Modern Architecture]]
> **Also known as:** Cloud Workload Protection Platform

**C**loud **W**orkload **P**rotection **P**latform. Runtime protection for VMs, containers, serverless.

**Context.** The runtime half of cloud workload security: agent or agentless protection for VMs, containers, and serverless — vulnerability state, behavioral detection, integrity monitoring. The agentless trend (snapshot scanning) trades depth for zero-friction coverage; most platforms now mix both.

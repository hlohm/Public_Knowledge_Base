# SSD

> **Branch:** [[02 - Hardware & Architecture|Hardware & Architecture]]
> **Also known as:** Solid State Drive

Non-volatile storage built from flash memory with no moving parts, vastly faster than a spinning hard disk, especially for random access.

**Context.** Flash cells wear out after a finite number of writes, so SSDs use wear-levelling and over-provisioning; this is also why secure erasure differs from on an HDD. NVMe over PCIe removed the old SATA bottleneck.

# Bytecode

> **Branch:** [[07 - Programming Languages|Programming Languages]]

A compact, portable intermediate instruction set for a virtual machine — between human-readable source and native machine code.

**Context.** The 'compile once, run anywhere' enabler: JVM bytecode, .NET CIL, Python's .pyc, WebAssembly. A VM either interprets it or JIT-compiles it to native code at runtime, decoupling the language from the hardware.

# Need to Know

> **Domain:** [[01 - Core Principles|Core Principles & Models]]

Stricter cousin of least privilege focused on *information* rather than *permissions*. Common in classified environments.

**Context.** Least privilege says a backup operator may read all file shares; need to know asks whether they should be able to open the M&A folder while doing it. Encryption, DLP labels, and compartmentalization enforce it. Outside classified settings it shows up as data classification plus access scoping.

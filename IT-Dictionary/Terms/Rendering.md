# Rendering

> **Branch:** [[14 - Graphics, Media & HCI|Graphics, Media & HCI]]

The process of generating a 2D image from a model or scene description — computing colour for each pixel from geometry, materials, and lighting.

**Context.** Splits along a hard line: **real-time** rendering (games, ≥60 fps, every trick to fake it fast) vs **offline** rendering (film, hours per frame, physical accuracy). The same word covers rasterisation (fast, approximate) and ray tracing (slow, physically based) — increasingly hybridised in modern GPUs.

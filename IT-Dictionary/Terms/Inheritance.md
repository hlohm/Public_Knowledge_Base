# Inheritance

> **Branch:** [[07 - Programming Languages|Programming Languages]]
> **German:** Vererbung

An OOP mechanism where a class derives fields and behaviour from a parent class, modelling an 'is-a' relationship.

**Context.** Powerful but overused — deep hierarchies become brittle, and the modern guidance is 'favour composition over inheritance'. The fragile base class problem and the diamond problem (multiple inheritance) are why many newer languages prefer interfaces/traits and composition.

## Often confused with

- [[Composition over Inheritance]] — Inheritance reuses by subclassing (is-a); composition reuses by holding instances (has-a) and is usually more flexible.

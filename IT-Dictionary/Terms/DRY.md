# DRY

> **Branch:** [[08 - Software Engineering|Software Engineering]]
> **Also known as:** Don't Repeat Yourself

The principle that every piece of knowledge should have a single, authoritative representation in a system — avoid duplicating logic.

**Context.** Easily over-applied: the counter-wisdom 'duplication is far cheaper than the wrong abstraction' (Sandi Metz) is the necessary corrective. DRY is about *knowledge*, not about textually-similar code that happens to coincide. Premature DRYing couples things that should stay independent.

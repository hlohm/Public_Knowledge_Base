# Unicode

> **Branch:** [[01 - Computing Foundations|Computing Foundations]]

A universal character set assigning a unique number (code point) to virtually every character in every writing system, plus emoji and symbols.

**Context.** Unicode is the *character set* (what characters exist and their numbers); an *encoding* like UTF-8 decides how those numbers become bytes. Conflating the two causes 'mojibake' — text decoded with the wrong encoding.

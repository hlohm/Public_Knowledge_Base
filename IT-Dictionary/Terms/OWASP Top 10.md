# OWASP Top 10

> **Domain:** [[08 - Application Security|Application Security]]

The must-know list of web application risks. Refresh on the current version — categories shift.

**Context.** Useful as a shared vocabulary and a floor, not a checklist — "we covered the Top 10" is not a security program. The 2021 edition's headline shift was Broken Access Control to #1 and the new Insecure Design category. Watch for the next revision; the categories track real-world breach data and move. (An LLM-specific Top 10 now exists too.)

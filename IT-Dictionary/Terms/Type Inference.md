# Type Inference

> **Branch:** [[07 - Programming Languages|Programming Languages]]

The compiler deducing types automatically from context, so you get static-typing guarantees without writing every annotation.

**Context.** What makes modern statically-typed languages feel light (Rust's `let`, Go's `:=`, `auto` in C++, Hindley-Milner in ML/Haskell). The guarantees of static typing without the verbosity — the reason the static-vs-dynamic ergonomics gap has narrowed.

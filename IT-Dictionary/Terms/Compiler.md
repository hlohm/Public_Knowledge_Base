# Compiler

> **Branch:** [[07 - Programming Languages|Programming Languages]]
> **German:** Compiler

A program that translates source code in one language into another (usually machine code or bytecode) ahead of execution, typically performing optimisation along the way.

**Context.** The classic phases — lexing, parsing to an AST, semantic analysis, optimisation, code generation — recur everywhere, not just in language compilers. Compile-time work is the price for runtime speed and early error detection. Contrast with interpreters, which translate as they run.

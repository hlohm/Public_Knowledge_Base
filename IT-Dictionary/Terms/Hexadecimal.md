# Hexadecimal

> **Branch:** [[01 - Computing Foundations|Computing Foundations]]
> **Also known as:** Hex, Base 16
> **German:** Hexadezimalsystem

Base-16 notation (digits 0–9 then A–F). Each hex digit maps to exactly 4 bits, so two hex digits = one byte.

**Context.** Used everywhere bytes are shown to humans: memory addresses, colour codes (#FF8800), MAC addresses, hashes. The clean 4-bit-per-digit mapping is the whole reason it won over decimal.

# RFC

> **Branch:** [[15 - Standards, Formats & Bodies|Standards, Formats & Bodies]]
> **Also known as:** Request for Comments

A numbered document in the series that defines internet protocols and conventions — HTTP, TCP, IP, SMTP, and the rest of the internet's standards live here.

**Context.** The primary, authoritative source for how internet protocols actually work — when in doubt, read the RFC. The culture is distinctive: the deliberately humble name ('request for comments'), the running joke of April Fools' RFCs, and 'rough consensus and running code' as the IETF ethos.

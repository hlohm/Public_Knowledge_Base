# C2 Framework

> **Domain:** [[12 - Offensive Security and Testing|Offensive Security & Testing]]

Tooling for managing implants (Cobalt Strike, Sliver, Mythic, Metasploit).

**Context.** The operator's console for managing implants — task them, pivot, exfiltrate — and the same tools serve red teams and real adversaries, which is the perennial dual-use tension. Cobalt Strike's leaked/cracked versions are everywhere in real intrusions; open-source Sliver and Mythic are common in both crime and authorized engagements. Detection focuses on their network and host artifacts (beacon patterns, default profiles).

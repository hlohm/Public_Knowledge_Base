# Token

> **Branch:** [[13 - AI & Machine Learning|AI & Machine Learning]]

The unit a language model processes — typically a sub-word chunk (roughly ¾ of a word in English), produced by a tokeniser from raw text.

**Context.** The model never sees characters or words, only token IDs, which explains a lot of LLM quirks (trouble spelling, counting letters, or doing arithmetic). Tokens are also the unit of pricing and of the context window, so 'how many tokens' is a constant practical concern.

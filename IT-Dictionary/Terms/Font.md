# Font

> **Branch:** [[14 - Graphics, Media & HCI|Graphics, Media & HCI]]
> **German:** Schriftart

A digital file defining the shapes (glyphs) of characters at a given style and weight. Modern formats (TrueType, OpenType) describe glyphs as scalable vector outlines.

**Context.** Technically a **font** is one style/weight and a **typeface** is the whole family, though everyday usage blurs them. OpenType packs in ligatures, alternates, and variable axes (one file morphing weight/width). Web fonts (WOFF2) made typography on the web rich — at a page-weight and privacy cost.

# GPU

> **Branch:** [[02 - Hardware & Architecture|Hardware & Architecture]]
> **Also known as:** Graphics Processing Unit

A processor with thousands of simple cores optimised for doing the same operation across huge amounts of data in parallel (originally pixels).

**Context.** That same data-parallel design turned out perfect for matrix maths, which is why GPUs power modern machine learning. The CPU/GPU split is latency-optimised (few fast cores) vs throughput-optimised (many slow cores).

# SWG

> **Domain:** [[10 - Cloud and Modern Architecture|Cloud & Modern Architecture]]
> **Also known as:** Secure Web Gateway

**S**ecure **W**eb **G**ateway. Proxy enforcing web access policy.

**Context.** The cloud successor of the on-prem proxy appliance: URL filtering, malware scanning, and increasingly TLS inspection and DLP, enforced wherever the user sits — which is the point, since the office-only proxy stopped covering reality around 2020. Usually consumed as part of an SSE bundle rather than standalone.

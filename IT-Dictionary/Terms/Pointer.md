# Pointer

> **Branch:** [[07 - Programming Languages|Programming Languages]]
> **German:** Zeiger

A value holding the memory address of another value. Dereferencing follows the address to read or write the target.

**Context.** Power and footguns in one concept: pointer arithmetic, manual memory management, and the entire class of bugs (dangling pointers, use-after-free, null dereference) that memory-safe languages exist to abolish. Understanding pointers is understanding how memory actually works.

- [[Reference]] — A pointer is an explicit, manipulable address (you can do arithmetic, it can be null); a reference is a safer, usually-immutable alias the language manages.

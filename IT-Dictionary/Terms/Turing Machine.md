# Turing Machine

> **Branch:** [[10 - Theory of Computation|Theory of Computation]]

An abstract machine — an infinite tape, a head that reads/writes symbols, and a state table — that formalises what it means to 'compute'. The reference model for computability.

**Context.** Not a blueprint for real computers but a definition of the computable: anything a Turing machine can compute is, by the Church-Turing thesis, what 'computable' *means*. 'Turing-complete' (a system that can simulate one) is the bar real languages clear — and accidentally so do things like SQL, TeX, and Magic: The Gathering.

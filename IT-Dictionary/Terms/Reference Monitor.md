# Reference Monitor

> **Domain:** [[01 - Core Principles|Core Principles & Models]]

The idealized enforcement point through which *every* access by every subject to every object is mediated. To count as a reference monitor it must be **always invoked** (no bypass path), **tamper-proof**, and **small enough to verify**.

# Socket

> **Branch:** [[04 - Networking|Networking]]
> **Also known as:** Network Socket

The OS endpoint for network communication, identified by IP + port + protocol; the programming interface apps use to send/receive.

**Context.** The Berkeley sockets API is the near-universal model; a socket is the file-descriptor-shaped handle your code reads and writes.
